Flow = net foreign (IDR) for the session, with the behavioural split beneath it — inst (JP Morgan, UBS, Mandiri, Verdhana, CLSA, Macquarie) · hnw (CGS, KB Valbury, BCA, Henan) · ret (Stockbit, Ajaib, Mirae). Flow signals override the price ladder: Retail trap = institutions selling while retail buys · Smart money = institutions accumulating while retail sells (HNW is shown for context but not required to agree — it is only four brokers and is noisy) · Quiet accumulation = institutions buying 3+ sessions with the price still flat · Scalper churn = heavy fast-money turnover that nets out flat (activity, not positioning) · Distribution (flow) = sustained institutional selling.
Groups breaks the same session down across all five cohorts — including scalper (MG) and other (unclassified brokers).
